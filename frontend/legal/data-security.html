Keamanan Data & Infrastruktur

Terakhir diperbarui: 24 Agustus 2026

1. Komitmen Keamanan Kami

Di PDF Master AI, menjaga keamanan dan kerahasiaan dokumen Anda adalah prinsip dasar operasional kami. Kami menerapkan arsitektur perlindungan berlapis untuk memastikan file PDF dan percakapan AI Anda terlindungi dari akses tanpa izin.

🔒 Enkripsi Transit (SSL/TLS)

Seluruh komunikasi data antara peramban Anda dan server kami dienkripsi menggunakan protokol HTTPS dengan sertifikat SSL/TLS 256-bit.

⚡ Pemrosesan Memori Sementara

Dokumen yang diunggah diproses di memori volatil (*RAM ephemeral*) dan segera dihapus otomatis setelah tugas selesai.

🧠 Ekstraksi Teks Lokal

Fitur pra-pemrosesan PDF menggunakan parser berbasis peramban (`PDF.js`) untuk meminimalkan transmisi mentah berkas.

🚫 Tanpa Pelatihan Model Publik

Data dokumen Anda tidak pernah digunakan untuk melatih ulang model kecerdasan buatan publik tanpa izin Anda.

2. Perlindungan Berkas PDF

Saat Anda menggunakan fitur kompresi, konversi, atau analisis PDF:

  • Penyimpanan Permanen Nol: Berkas PDF asli Anda tidak disimpan secara permanen di server publik.
  • Akses Terisolasi: Sesi pengolahan dokumen diisolasi secara ketat sehingga tidak ada pengguna lain yang dapat mengakses atau mengunduh dokumen Anda.

3. Keamanan Integrasi AI

Fitur obrolan AI berinteraksi dengan API Google Gemini melalui koneksi backend aman:

  • Teks dokumen yang dikirim ke AI dienkripsi selama transit.
  • Riwayat obrolan diikutsertakan dalam sesi aktif Anda dan dapat dibersihkan secara instan kapan saja menggunakan tombol "+ New Chat".

4. Praktik Terbaik Pengguna

Kami menyarankan beberapa langkah untuk menjaga keamanan akun dan dokumen Anda:

  • Selalu gunakan koneksi internet yang aman saat mengunggah dokumen sensitif.
  • Hindari membagikan tautan sesi atau tangkapan layar yang berisi kunci akses rahasia.
  • Gunakan tombol "New Chat" untuk menghapus konteks obrolan lokal setelah selesai menganalisis dokumen sensitif.
